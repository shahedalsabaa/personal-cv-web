# Modern Personal CV Web Page 📄✨

A clean, modern, and responsive Curriculum Vitae (CV) web page developed as part of the **Web Development 1** coursework at **Al-Aqsa University**.

The project focuses on mastering semantic HTML5 structure and clean CSS3 styling with an elegant dark theme.

---

## 🌟 Key Features & Implemented Tasks

- **Typography & Theme:** Styled using the Google Font `'Inter'` with an eye-friendly dark palette.
- **Floating Card Layout:** Wrapped in a central container featuring smooth `box-shadow` elevation.
- **Gradient Header:** Built with a linear gradient background (`135deg, #1a1a2e, #16213e`) and centered metadata.
- **Profile Avatar:** Circular photo profile with green border accents (`#4caf50`) and depth shadows.
- **Skill Badges:** Skills converted from standard lists into interactive tag badges/pills.
- **Clean Education Table:** Structured with borders, custom header background, and zebra-striping rows (`:nth-child(even)`).
- **Interactive Links:** Clean link styling with active hover transitions and dedicated `mailto:` / `tel:` handlers.

---

## 🛠️ Built With

- **HTML5:** Semantic markup (`header`, `table`, `ol`, `ul`, `figure`).
- **CSS3:** Custom styles, Flexbox-friendly alignment, Google Fonts, transitions, and gradient effects.
